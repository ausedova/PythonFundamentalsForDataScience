# Python Fundamentals for Data Science

## Artem Urlapov Sedova (Universidad Autónoma de Madrid y Universidad Europea de Madrid)

Curso intuitivo de Fundamentos de Python para Data Science.

Se cubren desde las bases computacionales hasta aspectos de carácter eminentemente práctico (tipos de objetos y estructuras, e iniciación a la programación y visualización de datos).

Con ejemplos propios (unos) y basados en “Artificial Intelligence with Python” (Teik Toe Teoh & Rong Zhen, Springer, 2022) (otros).
